## 🚀 Project Overview

The **Quiz Platform with Leaderboard** is a Java-based application that allows users to participate in quizzes, answer multiple-choice questions, calculate their scores, and view their position on a leaderboard.

The project demonstrates Java programming concepts such as **Object-Oriented Programming, collections, user input, conditional statements, loops, and data handling**.

---

## ✨ Features

* 📝 **Start Quiz** – Users can start and attempt a quiz.
* ❓ **Multiple-Choice Questions** – Each question provides multiple options.
* ✅ **Answer Evaluation** – Automatically checks whether the selected answer is correct.
* 📊 **Score Calculation** – Calculates the user's total score.
* 🏆 **Leaderboard** – Displays users ranked according to their scores.
* 👤 **User Details** – Stores the participant's name and score.
* 🔄 **Multiple Attempts** – Allows users to participate in the quiz again.
* 📋 **Result Display** – Shows the final score after completing the quiz.
